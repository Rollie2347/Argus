# Music for Instagram Reels

Instagram's website has no music picker, so the bot mixes one of these files
into each Reel (`lib/music.mjs` picks one not used recently; `lib/video.mjs`
loops and fades it). Any `.mp3 .m4a .wav .aac .ogg` dropped in this folder
joins the rotation; delete a file to retire it.

**Only put music here that you may use.** A commercial or trending song baked
into the file gets the Reel muted or removed.

## Where the current tracks came from

Downloaded 2026-10-04 from the Internet Archive's mirror of FreePD.com
(`https://archive.org/details/freepd`, folder `Page2/`); the files are tagged artist "Frank Nora". FreePD published its
whole catalogue as public domain (CC0); the site itself has since closed, and
the mirror item carries no licence field of its own — the CC0 claim rests on
FreePD's.
